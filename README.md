# 📈 기능 구현 리스트

### 1. 사용자 입력

- `@woowacourse/mission-utils`에서 제공하는 `Console.readLineAsync` 를 이용해 사용자 입력을 받는다.

- `덧셈할 문자열을 입력해 주세요.` 라는 문구가 나와야한다.

### 2. 입력값 파싱

- 입력한 문자열에서 구분자를 기준으로 숫자를 추출한다.

  - 구분자는 커스텀 구분자와 기본 구분자로 나뉜다.

    - 기본 구분자는 `쉼표(,)와 콜론(:)`을 기본 구분자로 사용하고 커스텀 구분자와 같이 사용이 가능하게 설계
    - ex) `//&\n1&2,3:4`

  - 커스텀 구분자는 `//`와 `\n` 사이에 위치하는 문자를 커스텀 구분자로 사용한다.

### 3. 숫자 계산

- 구분자로 분리된 숫자들을 더한다.

### 4. 결과 출력

- `@woowacourse/mission-utils`에서 제공하는 `Console.print` 를 이용해 계산 결과를 출력한다.

- `결과 : ${result}` 형식의 결과가 출력 되어야한다.

# 🤔 스스로 판단한 예외 처리

- 에러는 `[ERROR]`로 시작하는 에러 메시지를 출력 후 애플리케이션은 종료되어야 한다.
- 별도의 객체 형식의 에러 상수 파일을 만들어 사용

### 커스텀 구분자 에러

- **커스텀 구분자 형식이 있지만 빈 값일 경우**

  - ex) `//\n1,2`
  - `[ERROR] 커스텀 구분자가 비어 있습니다.`

- **커스텀 구분자의 길이가 1을 초과 할 경우**

  - 이 경우는 기능 요구 사항에 적힌  
    `문자열 앞부분의 "//"와 "\n" 사이에 위치하는 문자를 커스텀 구분자로 사용한다.`  
    에서 `문자를` → 한 글자만 가능으로 판단했다.

  - ex) `//&&\n1&&2`
  - `[ERROR] 커스텀 구분자는 한 문자만 입력할 수 있습니다.`

- **커스텀 구분자에 숫자가 들어간 경우**

  - ex) `//1\n112`
  - `[ERROR] 커스텀 구분자에는 숫자를 사용할 수 없습니다.`

### 사용자 입력 에러

- 음수를 입력할 경우

  - ex) `-1,2`
  - `[ERROR] 음수는 입력할 수 없습니다.`

- 유효하지 않은 문자를 입력할 경우

  - ex) `1, a` or `//&\n1$2`
  - `[ERROR] 구분자와 양수외에 잘못된 문자가 입력되었습니다.`

## 🤔 App.js에 방황한 로직들을 어떤 구조로 리팩토링 할까

- 공부가 목표기 때문에 사용 해보지 않았던 MVC 패턴으로 구조 설계
- Model, View, Controller 세가지의 역할로 구분

### Model

- **데이터와 비지니스 로직을 관리**

  - 커스텀 구분자 파싱
  - 커스텀 구분자 검증
  - 구분자를 기준으로 문자열 분리
  - 사용자 입력 검증
  - 덧셈 계산

### View

- **사용자의 UI를 담당**

  - 사용자 입력 받기
  - 결과 출력

### Controller

- **Model, View를 연결하고 전체 흐름 제어**
- App.js에서 컨트롤러를 실행
